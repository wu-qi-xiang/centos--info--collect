# DevOps Platform Next Optimizations

当前优先级清单已经完成一轮实现。下次继续建议从“后续增强建议”开始。

## 下一步优先级

1. [已完成] SSH Key 登录支持
   - 主机资产支持密码/密钥两种认证方式
   - 命令执行、文件分发、发布部署统一复用连接逻辑
   - 密钥内容加密存储

2. [已完成] 异步任务执行
   - 命令、批量任务、文件分发、发布部署改成后台执行
   - 页面显示执行中、完成、失败
   - 避免请求阻塞

3. [已完成] 审批流增强
   - 高危命令自动转审批
   - 发布/回滚可配置是否强制审批
   - 审批人、申请人不能为同一人
   - 审批通知

4. [已完成] 监控趋势图
   - 基于 `MetricSample` 展示 CPU、内存、磁盘趋势
   - 支持按主机、时间范围筛选

5. [已完成] 通知渠道
   - 企业微信、钉钉、Webhook
   - 告警、审批、发布结果通知

6. [已完成] 更细 RBAC
   - 按模块授权
   - 按主机组授权
   - 审计权限独立

7. [已完成] 生产化部署
   - `.env.example`
   - Gunicorn 或 uWSGI 配置
   - Dockerfile / docker-compose
   - 日志目录和静态文件收集

8. [已完成] 后台任务可靠性增强
   - 命令、批量任务、文件分发、发布和回滚执行入口增加领取/幂等保护
   - 已运行或已有结果的任务重复触发时不再重复 SSH 或重复创建结果行
   - 回滚空脚本和策略拦截明确落到失败终态，避免停留在运行中

9. [已完成] DevOps 控制台权限化与状态刷新
   - Vue 控制台模块入口按 `bootstrap.permissions` 过滤
   - 只展示当前用户有权访问的命令、任务、指标、审批、发布、文件和通知模块入口
   - 存在 `pending/running` 工作项时自动短轮询刷新状态，减少手动刷新

10. [已完成] 通知渠道增强
   - 钉钉加签配置页面提示和发送失败重试
   - 通知模板按事件类型可编辑
   - 通知日志支持按渠道、状态、事件类型筛选

11. [已完成] 标签主机范围授权
   - 主机范围支持按标签授权

12. [已完成] 生产运行基础增强
   - GitHub Actions 在 push 和 pull request 中执行 `manage.py check`、迁移检查、单元测试和技能校验
   - 支持从 SQLite 切换到 MySQL/PostgreSQL 的环境变量配置
   - 命令、批量任务、文件分发、发布部署和回滚由持久化独立 Worker 执行

13. [已完成] 共享导航权限
   - 共享侧边栏按模块权限上下文隐藏无权访问的 DevOps 入口

14. [已完成] Nginx 生产参考
   - 提供 PostgreSQL、Nginx、静态文件和反向代理的可选 Compose 生产参考

15. [已完成] AIOps LLM 密钥加密
   - AIOps LLM 密钥加密存储，留空更新时保留既有值

## 后续增强建议

1. RBAC 增强
   - 增加权限变更审计详情和删除/清空权限入口
